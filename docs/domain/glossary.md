# 用語集
- チェックロジック
  - `src`配下に格納されるロジックのこと
  - 「提供用CIテンプレートからチェックロジックを呼び出す」など大枠を説明する際に使用される
- MR
  - マージリクエスト
- チェックリスト
  - 複数のチェック項目で構成される
- チェック項目
  - 単一のチェック観点
- レビュー結果
  - AIによるレビューの結果
    - 一つのチェック項目に対して一つのレビュー結果が紐づく
  - 以下で構成される
    - コメント
      - ユーザが指定したフォーマットでAIがコメントを生成
    - 評定
      - ユーザが指定したラベル（A,B,C,...等）とラベル定義に従ってAIが評定をつける
- チェック対象
  - AIレビューの対象
  - CIテンプレート提供先のプロジェクト資源
- 品質ゲート
  - レビュー結果に基づいてパイプラインの成否を判定する仕組み
  - 失敗基準のリスト（評定ラベルとしきい値のペア）で構成される
  - いずれかの基準に抵触した場合にパイプラインを失敗とする（OR条件）
- レビュー設定
  - AIによるレビュー実行時にユーザがアレンジ可能な設定項目
  - 以下で構成される（全て任意、指定しない場合はデフォルト値が適用される）
    - 追加指示（AIレビュー実行時のシステムプロンプトに組み込まれる）
    - 同時レビュー項目数
      - AIのレビュー実行時に一度にいくつのチェック項目をレビューさせるか指定
    - コメントフォーマット
      - レビュー結果に含まれるコメントのフォーマット
    - 評定基準
      - 以下ペアのリストで構成される
        - ラベル（例：A）
        - ラベル定義（例：チェック項目の要件を完全に満たしている）
    - 非表示評定ラベル
      - コメントに表示しない評定のラベルリスト（例：["A"]）
      - 指定された評定の結果はコメント投稿時にメタデータ（隠しフィールド）に格納される
    - 品質ゲート
      - 失敗基準のリスト（評定ラベルとしきい値のペア）
      - 指定しない場合はデフォルト値（基準なし=品質ゲートなし）が適用される
